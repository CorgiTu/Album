# 专辑 (Album) - 跨平台歌单自动化同步工具

> **为什么叫「专辑」？**
> 因为它是**专门的合集**，也是**专门的编辑**。
> 本项目旨在打破音乐平台的版权与数据壁垒，让你能够轻松将全网的热门音乐、特定歌手的精选曲目，自动化汇聚并同步到你的网易云音乐账号中，打造真正属于你自己的"数字专辑"。

## 📥 下载与安装 (普通用户首选)

无需配置任何编程环境，开箱即用！

1. 前往本项目的 [Releases 页面](https://github.com/CorgiTu/Album/releases)。
2. 下载最新版本中的 `专辑.exe` 文件。
3. 双击运行即可。

*(注：首次运行可能需要稍微等待几秒钟解压环境)*

## 核心功能
* **🎯 批量歌手抓取 (New!)**：支持输入多个歌手名称（用逗号或空格分隔），一次性抓取多位歌手的金曲，生成终极合集。例如输入 `"周杰伦, 孙燕姿 陈奕迅"` 即可一次获取三位歌手的热门歌曲并合并输出。
* **⚡ 工业级并发架构 (New!)**：采用 `asyncio` 异步协程池 + `asyncio.Semaphore(5)` 并发控制器，网易云歌曲搜索匹配速度相较传统同步逻辑提升 500% 以上。配合 `ThreadPoolExecutor` 多线程协同，充分利用网络带宽与 CPU 资源。
* **🔌 热插拔插件系统 (New!)**：支持通过 `src/plugins/` 目录动态扩展数据源。开发者只需继承 `BaseCrawler` 并实现 `fetch(target, count)` 方法，即可零成本接入新平台爬虫，无需修改任何核心代码。
* **🌐 多平台数据源覆盖**：插件系统现已全面覆盖 **QQ音乐、网易云音乐、酷狗音乐、酷我音乐、汽水音乐、抖音热歌榜、B站音乐区** 等主流音乐阵地，打破版权壁垒，一键聚合全网热歌。
* **智能聚合与搜索**：输入歌手名称，一键跨平台抓取 Top 热门歌曲，并精准匹配网易云音乐曲库。
* **全网热歌盲盒**：支持在不输入歌手名的情况下，默认抓取全网实时热歌榜单，生成每日专属流行精选。
* **现代化桌面 UI**：基于 Flet 构建的流畅跨平台暗黑界面，彻底告别枯燥的命令行。
* **丝滑的进度反馈**：内置动态进度条与实时状态提示，网络请求再久也不假死，进度一目了然。
* **隐私安全的本地记忆**：Cookie 凭证仅在本地 `config.json` 加密持久化存储，一次登录，长久免密，绝对不上传任何隐私数据。
* **🔄 增量更新与智能查重 (New!)**：告别重复建单污染账号，支持将新抓取的曲目无缝追加到已有歌单中。内置集合运算查重，已有歌曲自动跳过，助你养成私人万首金曲库。

## 快速开始

### 1. 环境准备
确保你的电脑已安装 Python 3.10 或以上版本。克隆项目并安装依赖：
```bash
git clone https://github.com/CorgiTu/Album.git
cd Album
pip install -r requirements.txt
```

### 2. 获取登录凭证 (MUSIC_U)
为了保证连接的极度稳定，本项目采用 Cookie 直连方式：

- 在浏览器（推荐 Edge/Chrome）中打开并登录 [网易云音乐网页版](https://music.163.com)。
- 按 F12 打开开发者工具，切换到 **Application（应用程序）** 面板。
- 在左侧展开 Cookies，点击 `https://music.163.com`。
- 在右侧列表中找到 Name 为 `MUSIC_U` 的项，双击它的 Value 并复制。

### 3. 运行「专辑」
```bash
python src/main.py
```

在弹出的软件界面中，粘贴你刚刚复制的 Cookie，输入你想整理的歌手名字，点击"生成专属歌单"即可享受自动化的魔力！
